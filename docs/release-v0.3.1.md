# Codex Enhance v0.3.1

修复实时状态显示中的两个问题：

- 历史“等待”记录不再累积为并行调用，工具数量和阶段计时恢复准确关联。
- 短暂漏采样后，同一阶段的计时不会无故重置；工具与思考真正切换时仍重新计时。

缺少状态的记录会显示未知，不再默认当作运行中。
