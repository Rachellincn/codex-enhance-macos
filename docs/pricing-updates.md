# 模型价格更新

价格表与程序分开更新。浮窗启动时、运行中每 6 小时检查一次；「账号额度 → 刷新」也会检查。发现未收录的模型时会提前检查，重复失败最多每小时重试。

更新后自动用已保存的 token 记录重新计算本周期金额，不用重新安装，不修改原始对话，也不改变账号返回的额度百分比。已经归档的周记录保留当时的价格日期。

## 更新来源

浮窗读取本仓库的 [`collector/prices.json`](../collector/prices.json)。这是一份人工核对官方文档后发布的价格表，并非 OpenAI 提供的实时价格接口。

请求只有固定的公开文件地址，不包含账号、模型使用记录或对话内容。下载限时 5 秒、限长 64 KiB，只接收通过校验的 JSON 数据，不下载执行代码。断网、格式变化或远端版本过旧时保留现有价格，缺少价格的请求继续保留，价格补齐后再计算。

价格版本与日期可在额度快照及「计算明细」查看。本机缓存位于 `%LOCALAPPDATA%\CodexEnhance\pricing-cache.json`。

## 维护新模型

1. 核对官方模型页、API 价格和 Codex 速度规则，不能只按模型前缀套用旧价格。
2. 在 `collector/prices.json` 增加模型，填写单价、长上下文阈值及倍率、API Fast 和订阅 Fast 两种倍率，并更新 `sources`、`verifiedAt`、递增 `revision`。
3. 运行 `npm test` 后推送到 `main`。已经支持价格更新的客户端会自动获取；点「刷新」可立即检查。

`rates` 的顺序是输入、缓存读取、缓存写入、输出，单位为美元／百万 tokens；`longContext` 是输入阈值、输入／缓存倍率、输出倍率。没有已确认的倍率填 `null`，不猜测。保留旧模型规则，以便计算本周期既有请求。

GPT-6.1 Sol 于 2026-10-02 核对：输入 $2、缓存读取 $0.10、缓存写入 $2.50、输出 $10；API Fast 为 2 倍，订阅内 Fast 为 2.5 倍。超过 272K 输入时整次请求输入／缓存 2 倍、输出 1.5 倍。见 [官方模型页](https://developers.openai.com/api/docs/models/gpt-6.1-sol)、[Codex 速度规则](https://learn.chatgpt.com/docs/agent-configuration/speed)。

金额仍为本机用量等效估算，不是官方套餐余额或账单；API 价格和订阅额度不是同一个计费规则。
