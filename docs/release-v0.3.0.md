## 开始使用

下载下方 **CodexEnhance-v0.3.0-win-x64.zip**，完整解压，双击 **Start Codex.cmd**。可选运行 **Install.cmd** 创建桌面快捷方式。

需要已安装并登录 Windows Codex。发布包自带运行环境，无需安装开发工具。

升级前先从托盘退出旧版浮窗，再安装新版，设置会保留。

## 使用说明

金额为本机模型用量估算，不含语音与其他设备，非官方余额或账单。客户端更新可能影响连接。

本版通过自动化与原生界面检查。程序尚未签名，附 **SHA256SUMS.txt** 供校验。
