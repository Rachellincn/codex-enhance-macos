Codex Enhance 0.2.0 · Windows 状态浮窗
https://github.com/hrx114514x/codex-enhance

看清 Codex 正在做什么，以及哪里需要排查。

开始使用
1. 把压缩包完整解压到一个文件夹，不要只提取 EXE。
2. 确认已安装并登录 Windows Codex 桌面客户端。
3. 双击 Start Codex.cmd，打开 Codex 和状态浮窗。

如果 Codex 已在运行，启动入口会保留当前任务。当前实例未启用连接时，
请先保存工作并正常退出 Codex，再用 Start Codex.cmd 打开。
工具不会强制结束 Codex，也不会改动原来的快捷方式或自启动任务。

可选安装
双击 Install.cmd，可安装到当前用户目录，并创建桌面快捷方式：
「Codex + 状态浮窗」：打开客户端并连接浮窗。
「Codex 状态浮窗」：仅打开浮窗。
更新前先从托盘菜单退出旧版浮窗，再安装。设置会保留。

只想看看界面
双击 Preview.cmd。预览使用示例数据，不读取你的对话或账号。

使用入口
点击任务名：选择观察的任务。
跟随对话：在自动跟随当前页面与固定任务之间切换。
点击上下文/缓存/首字区域：打开性能详情。
点击账号额度：查看额度比例、重置倒计时和本机等效金额估算。
点击工具调用：查看分级记录和工具可用性检查。
更多菜单：连接诊断、主题、恢复位置和退出。

看不到浮窗
先打开 Codex 的主窗口；它最小化时浮窗也会隐藏。
查看系统托盘，选择「显示 / 隐藏」；也可恢复默认位置。
本版本适配 OpenAI.Codex Windows 程序包；非标准安装和客户端内部变化
可能影响连接。多个窗口/显示器仍需更多实机验证。

数据说明
会话与用量在本机处理，无需额外 API Key。
等效金额是本机估算，不是官方余额、账单或固定订阅上限。
目录已登记不等于工具执行成功；没有告警不表示所有功能都正常。
截图与预览中的所有数值都是示例。

退出与卸载
从托盘退出浮窗后，可删除解压目录。
若已安装，可删除 %LOCALAPPDATA%\Programs\CodexEnhance 和两个桌面快捷方式。
设置与派生缓存位于 %LOCALAPPDATA%\CodexEnhance；删除它们会重置本工具。
不要删除 %USERPROFILE%\.codex，它属于 Codex 的原始数据。
